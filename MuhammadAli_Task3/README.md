# TaskFlow — To-Do Web App (OIBSIP Task 3)

A responsive daily task manager built with HTML5, CSS3, and vanilla JavaScript.

## Features

- Add tasks immediately to the Pending Tasks list
- Mark tasks complete and move them to Completed Tasks
- Mark completed tasks pending again
- Edit task text inline
- Delete tasks from either list
- Pending and completed count indicators
- Friendly empty-state messages
- Timestamp when tasks are added and completed
- Persistent tasks using `localStorage`
- Responsive layout for desktop, tablet, and mobile
- No inline HTML `onclick` handlers
- Event listeners used for user interactions

## How to Run

Open `index.html` directly in a modern browser, or use VS Code with Live Server.

No build tools, npm packages, or server-side code are required.

## Data Persistence

Tasks are stored in the browser using `localStorage` under the key:

`taskflow-oibsip-tasks`

Clearing the browser's site storage will remove saved tasks.
