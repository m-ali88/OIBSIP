# Vanilla JavaScript Calculator

A browser-based calculator built with HTML5, CSS3, and vanilla JavaScript.

## Features

- Display for current expression and result
- Digits 0–9 and decimal point
- +, −, ×, ÷ operations
- Equals and clear buttons
- Backspace/delete
- Division-by-zero protection
- Operator chaining
- Standard arithmetic precedence (`5 + 3 × 2` = `11`)
- CSS Grid button layout
- JavaScript `addEventListener()` only; no inline `onclick`
- No `eval()`
- Keyboard support as a bonus

## Run

Open `index.html` directly in a browser, or use VS Code Live Server.
