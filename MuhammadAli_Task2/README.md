# Albert Einstein Tribute Page — OIBSIP Task 2

A responsive tribute page dedicated to Albert Einstein, created using HTML5 and CSS3.

## Objective

Design a visually engaging tribute page for a historical figure, scientist, artist, or public figure.

## Tech Stack

- HTML5
- CSS3
- Google Fonts
- No JavaScript required

## Features

- Subject name and one-line tagline
- Prominent public-domain Wikimedia Commons image
- Four original/paraphrased biography paragraphs
- Styled timeline of key achievements
- Distinctive quote block
- Multiple background colours
- Serif and sans-serif typography
- Responsive layout for desktop, tablet, and mobile
- Accessible image alt text and semantic HTML
- External links with `target="_blank"` and `rel="noopener noreferrer"`

## How to Run

Open `index.html` directly in a browser, or use VS Code with Live Server.
